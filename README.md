# JS Applications Studio

A lightweight JavaScript portfolio project demonstrating asynchronous
programming, timer mechanics, dynamic DOM manipulation, and UI color switching.

📌 Features

- **Color Switcher:** Generates random background colors on demand using an
  interval-based color generator.
- **Countdown Timer:** Provides a real-time countdown to a selected target date
  and time.
- **Promise Generator:** Creates a customizable series of asynchronous promises
  with dynamic delays and random success/failure outcomes using notifications.
- **Multi-Page Navigation:** Simple HTML navigation connecting all three
  interactive tools.

🛠️ Built With

- HTML5 / CSS3
- Vanilla JavaScript (ES6+)
- **Parcel** (web application bundler)

💻 How to Run

1. Clone the repository: `git clone <repository-url>`
2. Install dependencies: `npm install`
3. Start the development server: `npm start`
